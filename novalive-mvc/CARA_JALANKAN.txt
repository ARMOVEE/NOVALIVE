A. LANGKAH INSTALASI
----------------------------------------------------------------------
1. Pastikan Apache & MySQL pada XAMPP Control Panel sudah aktif.
2. Impor Database:
   - Buka phpMyAdmin (http://localhost/phpmyadmin/)
   - Buat database `db_novalive` (atau impor langsung file database/novalive.sql)
   - Atau lewat CLI:
     php bin/seed-admin.php
3. Salin konfigurasi lingkungan:
   - File `.env` sudah disiapkan dari `.env.example`.
4. Jalankan Server Pengembangan:
   Buka terminal di folder project C:\xampp\htdocs\NOVALIVE\novalive-mvc, lalu ketik:
     php -S localhost:8000 -t public public/router.php
5. Buka browser ke alamat:
     http://localhost:8000
